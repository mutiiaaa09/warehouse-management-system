> **Sistem Informasi Manajemen Gudang** berbasis web untuk perusahaan Telkom.  
> Kelola data barang, gudang, transaksi, dan laporan operasional secara terintegrasi.

---

## 📋 Fitur Utama

| Modul | Deskripsi |
|-------|-----------|
| 🔐 **Login** | Autentikasi multi-level (Admin, Operator, Umum) |
| 📦 **Master Barang** | CRUD data barang (nama, stok, lokasi, kategori) |
| 🏗️ **Master Gudang** | CRUD data gudang (nama, lokasi, kapasitas) |
| 📊 **Transaksi** | Pencatatan barang masuk & keluar |
| 📑 **Laporan** | Daftar barang, daftar gudang, rekap barang |
| 👥 **Manajemen User** | Tambah user, reset password (khusus Admin) |
| 🔒 **Keamanan** | Session-based authentication, password terenkripsi MD5 |

---

## 🚀 Teknologi yang Digunakan

- **Backend** : PHP 7.4+
- **Database** : MySQL 5.7+ (phpMyAdmin)
- **Frontend** : HTML5, CSS3, Bootstrap 5, JavaScript
- **Library** : Bootstrap Icons, Google Fonts (Inter)
- **Server** : XAMPP / Laragon / Apache
